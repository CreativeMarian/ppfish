# ppfish 服务器部署指南（Linux · 宝塔面板）

> 本包由本机（Windows 开发环境）打包生成，含完整源码 + 数据库备份（`backups/xianyu_data_full.sql`）。
> 覆盖两种部署方式：**方案 A（Docker，推荐）** 与 **方案 B（宝塔原生）**。

---

## 一、包内容说明

| 内容 | 位置 | 说明 |
|------|------|------|
| 项目源码 | 压缩包内全部目录 | backend-web / websocket / scheduler / frontend / common 等 |
| 数据库备份 | `backups/xianyu_data_full.sql` | 65 张表全量数据（含 19 个商品、蜜蜂卡券配置、闲鱼账号、系统配置） |
| 环境配置 | `.env` | 已含蜜蜂汇云 MF_APP_KEY/SECRET、端口等（见第五节） |
| 构建/部署脚本 | `build.sh` / `deploy.sh` / `deploy_remote.sh` | 项目自带 |

> ⚠️ 安全提醒：`.env` 与数据库含闲鱼账号密码（明文）、蜜蜂密钥等敏感信息，服务器上务必限制权限，不要暴露公网。

## 二、方案 A：Docker 部署（推荐，项目原生支持）

> 宝塔面板自带 Docker 管理器，也可用命令行。此方案 MySQL/Redis 与应用全部容器化，一条命令构建启动。

### 2.1 服务器准备

- 系统：Ubuntu 20.04+ / CentOS 7.9+ / 宝塔面板支持的系统
- 配置建议：4 核 8G 起（Playwright 浏览器 + 4 个服务）
- 安装 Docker：宝塔 → 软件商店 → 搜索「Docker管理器」安装；或命令行
  ```bash
  curl -fsSL https://get.docker.com | bash
  systemctl enable docker && systemctl start docker
  ```

### 2.2 上传源码

1. 将本压缩包解压到服务器，例如 `/opt/ppfish`
2. 确认目录包含 `build.sh`、`docker-compose.yml`、`backend-web/`、`frontend/` 等
3. 如果服务器上没有解压工具：`apt install unzip -y`（Ubuntu）或 `yum install unzip -y`（CentOS）

### 2.3 准备数据库备份文件

把 `backups/xianyu_data_full.sql` 放到服务器 `/opt/ppfish/backups/` 下（用于容器启动后导入，见 2.6）。

### 2.4 配置 .env

编辑 `/opt/ppfish/.env`（本包已带，按需修改）：

```env
# MySQL（容器内置）
MYSQL_ROOT_PASSWORD=your_password
MYSQL_DATABASE=xianyu_data
MYSQL_USER=xianyu
MYSQL_PASSWORD=your_password

# Redis
REDIS_PASSWORD=your_password
REDIS_DB=0

# 端口（若被占用可改）
FRONTEND_PORT=9000
BACKEND_WEB_PORT=8089
WEBSOCKET_PORT=8090
SCHEDULER_PORT=8091

# 蜜蜂汇云（已在 .env 中，保持即可）
MF_APP_KEY=your_mf_app_key
MF_APP_SECRET=your_mf_app_secret
MF_BASE_URL=https://merchant.task.mf178.cn
# ⚠️ 重要：充值页公网地址（买家点链接访问）。部署后改为你的域名或公网地址，如：
# MF_RECHARGE_BASE_URL=https://hf.yourdomain.com
# 不改为公网地址时，买家收到的充值链接是 127.0.0.1，无法打开
MF_RECHARGE_BASE_URL=http://127.0.0.1:9000
```

### 2.5 构建并启动

```bash
cd /opt/ppfish
chmod +x build.sh
bash build.sh rebuild
```

> 首次构建需编译 Python 依赖 + 下载 Playwright 浏览器（约 1-3GB），视服务器带宽 10-40 分钟，属正常。
> 构建完成后自动启动 6 个容器（mysql/redis/backend-web/websocket/scheduler/frontend）。

### 2.6 导入数据库（重要）

容器启动后，MySQL 是全新的空库，**必须导入本包的数据库备份**：

```bash
# 找到 mysql 容器
docker exec -i xianyu-mysql mysql -uroot -pyour_password xianyu_data < /opt/ppfish/backups/xianyu_data_full.sql
```

> 若提示 Unknown database，先建库：
> ```bash
> docker exec xianyu-mysql mysql -uroot -pyour_password -e "CREATE DATABASE IF NOT EXISTS xianyu_data CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
> ```
> 导入后重启应用容器让它们读到数据：`docker compose restart backend-web websocket scheduler`

### 2.7 验证

```bash
curl http://127.0.0.1:8089/health    # 期望 {"success":true,...}
curl http://127.0.0.1:8090/health
curl http://127.0.0.1:8091/health
curl -I http://127.0.0.1:9000       # 前端
# 浏览器访问 http://服务器IP:9000  → 登录 admin / admin123
```

### 2.8 常用命令

```bash
cd /opt/ppfish
bash build.sh logs      # 查看日志
bash build.sh restart   # 重启
bash build.sh stop      # 停止
docker exec -i xianyu-mysql mysql -uroot -pyour_password xianyu_data   # 进数据库
```

## 三、方案 B：宝塔原生部署（不使用 Docker）

> 与 Windows 本地部署思路一致：宝塔装 MySQL/Redis + Python venv + Node 构建前端 + supervisor 守护 + nginx 反代。

### 3.1 宝塔安装依赖

宝塔面板 → 软件商店安装：
- **MySQL 8.0**（root 密码自定，建库 `xianyu_data`，utf8mb4）
- **Redis 7**
- **Python 项目管理器**（或系统 Python 3.11+，含 pip）
- **Node.js 18+**（前端构建用）
- **Nginx**

### 3.2 上传源码

解压到 `/www/wwwroot/ppfish`（示例）。

### 3.3 建库 + 导入

```sql
CREATE DATABASE IF NOT EXISTS xianyu_data CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

导入备份：
```bash
mysql -uroot -p你的密码 xianyu_data < /www/wwwroot/ppfish/backups/xianyu_data_full.sql
```

### 3.4 配置 .env

编辑 `/www/wwwroot/ppfish/.env`：
```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=your_mysql_user
MYSQL_PASSWORD=你的MySQL密码
MYSQL_DATABASE=xianyu_data
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=你的Redis密码(没有则为空)
REDIS_DB=0
BACKEND_WEB_PORT=8089
WEBSOCKET_PORT=8090
SCHEDULER_PORT=8091
WEBSOCKET_SERVICE_URL=http://127.0.0.1:8090
SCHEDULER_SERVICE_URL=http://127.0.0.1:8091
BACKEND_WEB_SERVICE_URL=http://127.0.0.1:8089
STATIC_DIR=static
TZ=Asia/Shanghai
MF_APP_KEY=your_mf_app_key
MF_APP_SECRET=your_mf_app_secret
MF_BASE_URL=https://merchant.task.mf178.cn
MF_RECHARGE_BASE_URL=你的公网充值页地址
```

### 3.5 安装 Python 依赖（三个服务）

```bash
cd /www/wwwroot/ppfish

# backend-web
cd backend-web && python3 -m venv .venv
.venv/bin/pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple

# websocket（需补装公共依赖）
cd ../websocket && python3 -m venv .venv
.venv/bin/pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/pip install bcrypt passlib "python-jose[cryptography]" pycryptodome qrcode email-validator DrissionPage -i https://pypi.tuna.tsinghua.edu.cn/simple

# scheduler
cd ../scheduler && python3 -m venv .venv
.venv/bin/pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/pip install bcrypt passlib "python-jose[cryptography]" pycryptodome qrcode email-validator DrissionPage -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.6 安装 Playwright 浏览器

```bash
export PLAYWRIGHT_DOWNLOAD_HOST="https://cdn.npmmirror.com/binaries/playwright"
cd /www/wwwroot/ppfish/backend-web
.venv/bin/python -m playwright install chromium
.venv/bin/python -m patchright install chromium
```

> Linux 下还需系统依赖：`playwright install-deps chromium`（root 执行）。

### 3.7 构建前端

```bash
cd /www/wwwroot/ppfish/frontend
npm install --registry=https://registry.npmmirror.com --no-audit --no-fund
npm run build
# 产物在 frontend/dist，由 nginx 指向
```

### 3.8 supervisor 守护三个后端

宝塔 → 软件商店 → 「Supervisor管理器」→ 添加进程：

| 名称 | 启动目录 | 启动命令 |
|------|---------|---------|
| ppfish-backend | /www/wwwroot/ppfish/backend-web | /www/wwwroot/ppfish/backend-web/.venv/bin/python main.py |
| ppfish-websocket | /www/wwwroot/ppfish/websocket | /www/wwwroot/ppfish/websocket/.venv/bin/python main.py |
| ppfish-scheduler | /www/wwwroot/ppfish/scheduler | /www/wwwroot/ppfish/scheduler/.venv/bin/python main.py |

### 3.9 nginx 站点配置

宝塔 → 网站 → 添加站点（或修改现有站点的配置文件）：

```nginx
# 主站（前端 + API 代理）
server {
    listen 80;
    server_name yourdomain.com;   # 你的域名或服务器IP

    # 前端（构建产物）
    root /www/wwwroot/ppfish/frontend/dist;
    index index.html;
    try_files $uri $uri/ /index.html;

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8089;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态资源
    location /static/ {
        alias /www/wwwroot/ppfish/static/;
    }
}

# 充值页（可选独立域名，供买家访问充值页）
server {
    listen 80;
    server_name hf.yourdomain.com;
    location / {
        proxy_pass http://127.0.0.1:8089;
        proxy_set_header Host $host;
    }
}
```

## 四、域名与充值页公网（关键）

- 系统默认充值页地址 `MF_RECHARGE_BASE_URL=http://127.0.0.1:9000` **只在服务器本机能打开，买家打不开**。
- 部署后**必须**把它改成公网可访问地址：
  - 有域名：`https://hf.yourdomain.com`（nginx 反代到 8089）
  - 无域名：服务器公网 IP + 端口，如 `http://123.45.67.89:8089`（需安全组放行）
- 修改后重启 backend-web 生效。

## 六、常见问题

| 问题 | 解决 |
|------|------|
| 容器启动报数据库连接失败 | MySQL 容器未就绪，等 30 秒后 `docker compose restart`；确认 .env 密码与 compose 一致 |
| 导入 SQL 报 Unknown database | 先建库再导入（见 2.6） |
| 前端打不开 | 确认 frontend 构建成功；nginx 指向 frontend/dist |
| Playwright 下载失败 | 设 `PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright` 重试；Linux 跑 `playwright install-deps` |
| 登录滑块过不去 | websocket 服务需正常（8090）；DrissionPage 兜底引擎默认关闭，可开启 `CAPTCHA_DRISSIONPAGE_FALLBACK_ENABLED=true` |
| 闲鱼扫码登录失败 | 确认服务器能访问闲鱼；websocket 日志查看具体错误 |
| 充值链接打不开 | `MF_RECHARGE_BASE_URL` 未改公网地址（见第四节） |
| 蜜蜂放单报错 | 确认 .env 的 MF_APP_KEY/SECRET/MF_BASE_URL 正确；服务器时区 `TZ=Asia/Shanghai`（签名用服务器时间） |
